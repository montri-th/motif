Each motif has six static surfaces. Prefer `transparent-ink` on light surfaces and `transparent-mint` on brand blue or dark surfaces. Use boxed assets where the host surface cannot be controlled.

For motion, inline a string from `ijji-motifs.js` and load `ijji-motion.css` only while a real pending operation exists. Keep the motif `aria-hidden`; show visible status and elapsed time; provide cancel; remove the animation on success, failure, cancel, or timeout. Do not use it as ambient motion.
