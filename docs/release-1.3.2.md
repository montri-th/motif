# Motif Studio 1.3.2

Published source guidance targets the complete LDS 0.9.7 normative. This is a documentation and integration-kit update; it does not introduce a new motif, identity rendition or motion implementation.

- Current normative links point to LDS 0.9.7. Its Story supporting colours and analytical scales, including Location Intelligence role colours, use the released original HEX/LUT values unchanged across light and dark modes. Foundation UI and categorical colours retain the released theme rules.
- Original Landometer, ijji and CityChat identity/motif/motion source bytes and their permissions remain intact. The palette rule does not authorize recolouring identity artwork or changing motion.
- Studio 1.3.0 and 1.3.1 ZIPs remain byte-for-byte historical downloads. The current 1.3.2 kit is additive and excludes those archives to avoid nesting distributions.
- The current manifest and exact-byte integration checks describe the new kit. Local packaging does not by itself establish live deployment or account installation.
